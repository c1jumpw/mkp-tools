Quick start

My PD is your personal development library: audio, video and documents you return to, plus a Vault for the words and ideas you want to keep. It runs in the browser and works best on a phone.

  1. 1UnlockEnter the four-digit passcode. Each phone or computer asks once, then remembers.
  2. 2Press Play on Today's PracticeA track from your library, picked fresh each day. It keeps playing while you browse or lock the screen.
  3. 3Keep what stands outPause, open the Vault and tap + New term. The entry links back to the exact moment you heard it.

Open it at mypd.mkcworkspace.com. In Safari, tap Share, then Add to Home Screen: My PD gets its own icon and opens like an app.

Browsing the library

Browse shows the folders and files in your library. Open a folder to see what's inside; the path above the list shows where you are. Tap a file to open it: audio plays in the mini-player, video and documents open in a viewer.

Grid view

Listening

Audio plays in the mini-player at the bottom of the screen, so you can keep browsing. It keeps playing when the screen locks, with play, pause and skip on the lock screen. If a track has a transcript, tap Transcript to follow along.

{{FIG:player}}
  • Speed is remembered, so a track you start tomorrow plays at the speed you last chose.
  • "No transcript yet" means nobody has added one. Admins can add one; see Transcripts.
  • Starting another track replaces the one playing.

The Vault

The Vault is your personal knowledge base. It sits beside the media library but is stored separately, so entries don't show up in Browse. It holds three kinds of entry:

🔤 TermsA word or phrase, in any language. Definition, example and your notes.
📚 TopicsA concept to understand properly. A simple explanation first, a full one when you want it.
💡 IdeasYour own thoughts. Your note stays word for word, with an AI summary and your reflection beside it.

Saving a term while you listen

  1. Pause the track at the moment you heard it.
  2. Open the Vault tab, stay on Terms and tap + New term.
  3. Type the word and tap Look it up. Edit anything you like.
  4. Add subjects, ask a follow-up if you want, and tap Save to vault.
{{FIG:term}}
Keep the answers you want. Follow-up answers disappear when the sheet closes. Tap + Add to notes on any answer you want to keep before you save.

Topics

For a concept you want to understand rather than define. Name it, tap ✨ Explain simply, and expand it into a full explainer when the simple version isn't enough.

Admin

Admin · Organize on

Organize mode

Turn on the Organize switch at the top right. Every file gets five tools, + New folder appears beside + Upload, and Trash appears at the end of the Library. Turn it off again for everyday listening. With Organize on, tapping a row's title still plays it.

{{FIG:organize}}
Saves take a few seconds. Each change is saved straight to the library on GitHub. If you see "Move failed … replication delay", wait a moment and try again.
Admin

Uploading files

  1. Open the folder you want the files in, or a collection.
  2. Tap + Upload and pick one or more files.
  3. Keep the screen on until every file says Done, then tap Done.
{{FIG:upload}}
  • Audio: mp3, m4a, wav, aac, flac, ogg. Video: mp4, mov, m4v, webm. Documents: pdf, doc, docx, txt, md.
  • If a file with the same name is already in the folder, the app asks before replacing it. Its summary and transcript stay attached to the new file.
  • Uploading while a collection is open adds the files to that collection.
  • An interrupted upload leaves nothing half-saved behind. Upload the file again.
  • + Upload only puts files inside the library. To update the app itself, see Setup.
Admin · Organize on

Renaming and moving

Tap ✎ on a file to rename it. The field opens under the row.

{{FIG:rename}}

Tap ⇄ to move a file. Type the folder name as it appears in Browse, such as Wealth, or a path such as Wealth/2026 for a folder inside a folder. Leave it blank to move the file to the top of the Library.

Renaming and moving don't upload anything again, so even large files move in seconds. The summary, transcript, cover and collection tags go with the file. To make a new folder, open the folder it should sit in and tap + New folder.

Transcripts

The app can't turn speech into text by itself. You either tap along while you listen, or paste a transcript you already have, such as captions from YouTube or a transcription app.

  1. Turn on Organize and play the track.
  2. Tap Transcript in the mini-player, then + Add transcript (or ✎ Edit transcript).
  3. Choose Tap along or Paste text, then tap Save transcript.

Setup and settings

My PD has three parts. The app is a single page. Your files live in a GitHub repository. A small relay on Cloudflare holds the keys, so the app never needs a GitHub token on your phone.

The app's own files (index.html, this guide and changelog.json) live in the GitHub repo c3jumpw/mkp-tools, folder pdl. Vercel publishes them to mypd.mkcworkspace.com about a minute after every push. The library itself stays in c1jumpw/mkp-tools, folder pdl/media: the app reads it from there and the relay saves to it. The old address, c1jumpw.github.io/mkp-tools/pdl/, forwards visitors to the new one.

Common admin tasks

Change the passcode

  1. In pdl/index.html in c3jumpw/mkp-tools, find const PASSCODE and set four new digits.
  2. To make every device ask again, also change pdl_unlocked_v1 on the next line to pdl_unlocked_v2. Otherwise devices that already unlocked stay unlocked.
  3. Add an admin note to changelog.json and commit both. Vercel publishes in about a minute.

Update the app or this guide

  1. Change the files in pdl/ of c3jumpw/mkp-tools, on GitHub or in a Claude session with that repo.
  2. Add a release to changelog.json in the same commit, so people see What's new. See Change log.
  3. Push to main. Vercel publishes mypd.mkcworkspace.com in about a minute.
  4. The Uploader and + Upload still write to the library in c1jumpw/mkp-tools, not to the app.

Replace the GitHub token

  1. When saves fail with "Bad credentials", the token has expired.
  2. On GitHub, create a fine-grained token with Contents: Read and write on c1jumpw/mkp-tools (the library) and any repo the Uploader writes to.
  3. In Cloudflare, open the pdl-relay Worker → Settings → Variables and Secrets, replace GITHUB_TOKEN, and deploy.

Check the relay is running

  1. Open the relay address from CONFIG.WORKER_URL in a browser.
  2. "Missing or invalid app key" means it's running and answering. That reply is expected.
  3. An error page, or no reply, means the Worker is down or its address has changed.

Give someone access

  1. Send them mypd.mkcworkspace.com and the passcode.
  2. They'll have everything in this guide, including Organize.
  3. To take access away, change the passcode and the unlocked key, as in Change the passcode.

Find a deleted file

  1. Within 30 days: turn on Organize, open Trash and tap ↩.
  2. After that, or after Delete forever: it's still in the repo's history on GitHub, in the commit that deleted it.

    Help

    A file I just uploaded isn't showing

    Pull down from the top of the list and let go. GitHub's file list can lag for a few minutes; a refresh skips that delay.

    "Move failed … replication delay"

    GitHub sometimes needs a few seconds after one save before the next. Wait a moment and try again. Nothing is lost.

    Summarize says there's nothing to read

    The AI reads transcripts and text files; it can't listen to audio. Add a transcript first, or write the summary yourself.

    An upload stopped partway

    The screen locked or the signal dropped. Nothing half-finished is saved, so upload the file again and keep the screen on until it says Done.

    The Vault shows an error instead of my entries

    The Vault is reached through the relay. Check the relay is running (see Setup), then check SUPABASE_URL and SUPABASE_SERVICE_KEY in the Worker.

    Look it up, Explain or Summarize doesn't work

    These use Gemini through the relay. Check that GEMINI_API_KEY is set in the Worker and that the key still has quota.

    A new cover isn't showing on my other phone

    Covers can take a few minutes to reach other devices. The device you saved on shows it straight away.

    Video sound carries on after I lock the screen

    That's on purpose, so you can keep listening. Use the lock-screen controls, or close the video to stop it.

    Today's Practice is the same track all day

    That's on purpose. It changes at midnight and only picks audio, never anything in Trash.

    The Guide button shows a "404" page

    guide.html is missing from the pdl folder of c3jumpw/mkp-tools. Commit it next to index.html.

    mypd.mkcworkspace.com doesn't open

    Check the mypd record in GoDaddy DNS and the Domains page of the Vercel project (see Setup). A new or changed record can take up to an hour to spread.

    I'm asked for the passcode again at the new address

    Each address keeps its own settings on your device, so the first visit to mypd.mkcworkspace.com asks once, and theme and speed start fresh.

    I didn't see What's new, or I closed it too soon

    It shows once per update on each device. Everything it said is in the Change log.

    I forgot the passcode

    An admin can find it in index.html by searching for PASSCODE.
